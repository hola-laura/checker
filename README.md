# Homeownership Checker

A browser-based demo for reviewing homeownership and mortgage journey copy against public regulation and writing guidance.

## Open the demo

The app is `index.html`. It supports pasted copy and exported PNG/JPG screens. Screen text is read in the browser; live Figma links are not connected in this demo.

## Use

Open `index.html` in a browser or enable GitHub Pages for a hosted version.

This is a design review aid, not legal advice or a substitute for compliance review.
